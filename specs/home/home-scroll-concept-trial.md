# Connected Home — owner-approved trial, 2026-11-03

## Experience specification

The owner approved the five-chapter storyboard, continuous native scrolling and
then a real trial. Deliver `/en/home-concept` without replacing Home or adding a
navigation entry. Exclude it from indexing and the sitemap. It is an isolated
reviewable experiment, not the new Home architecture.

Arrival → Meet Meowhe → Colorway studies → Made at Luminal → Collect. One model
connects the first two scenes. The same three photos open as bubbles and become
gallery frames. Gallery gives way to a finished surface study beside four craft
steps. Collect scrolls naturally with real Shop, Raffle, Archive and Commission
links; no invented release/availability claims.

Do not intercept wheel, touch or keyboard events; no mandatory snapping, body
scroll locks or additional dependencies. Reverse scrolling uses the same timeline.
Keep one primary motion per viewport. Phones, coarse pointers, short screens and
reduced motion use normal document flow, real images and zero 3D initialization.
All text and links remain usable without JavaScript.

## Asset and content boundary

Use the existing published ERP web-model configuration and public photographs.
Autoplay is disabled in this trial so it does not compete with scroll motion.
Do not publish manufacturing masters. No making-process photo set is installed:
label the craft image as a finished-object surface study rather than pretending
it documents casting. Actual process photography is a gap before promotion.

The preview remains request-bound and reads the published Hero configuration via
the existing service. A scoped noscript rule reveals this route's completed HTML
inside the inherited streaming boundary and hides its loading shell. The rule
uses the base cascade layer to override Tailwind's important hidden declaration.
It never changes hidden state in JavaScript sessions or on another route.
The original Home and current-raffle discovery remain unchanged.

## Technical plan

- Thin noindex route composes existing Header/Footer and server-rendered content.
- Narrow client mounts the existing HeroObjectStage only on eligible desktop.
- Dynamically load the installed GSAP/ScrollTrigger on eligible devices only.
- CSS grid overlays one sticky visual on native chapter sections; a scrubbed
  timeline moves the model and morphs the same photo elements into gallery frames.
- Default CSS is static flow; failed enhancement keeps the complete static page.
- Revert GSAP context and remove media listeners on unmount/capability change.
